Architecture

LiteLLM proxy + 6 vLLM containers, all on one MI300X. Bound to 127.0.0.1.

┌──────────────────┐    ┌──────────────────────┐    ┌──────────────────────────┐
│   Mac (laptop)   │    │  LiteLLM proxy       │    │  AMD MI300X (192 GB)     │
│                  │ ───→  127.0.0.1:8000   ───→ │                          │
│  Streamlit + CLI │    │  routes by model     │    │  vLLM :8001 Qwen-7B      │
│                  │    │                      │    │  vLLM :8002 Phi-3.5      │
│  via SSH tunnel  │    │                      │    │  vLLM :8003 Falcon3-7B   │
└──────────────────┘    └──────────────────────┘    │  vLLM :8004 Hermes-3-8B  │
                                                     │  vLLM :8005 InternLM-7B  │
                                                     │  vLLM :8006 Yi-1.5-9B    │
                                                     └──────────────────────────┘

Each vLLM at --gpu-memory-utilization 0.13. All six fit in 192 GB at FP16 with ~22 GB headroom.

Trust pack — what makes findings falsifiable

1. Evidence citation

One verbatim quote per attributed reviewer. Auditable claims.

2. Self-disclosure metadata

run_id · ISO timestamp · per-persona model map · distinct-model count · token usage.

3. Prompt-injection defense

SECURITY NOTICE prefix + <<USER_INPUT>> markers wrap untrusted text.

4. Input length cap

20k char hard limit. Token-exhaustion DoS is not a viable attack.

5. OWASP regex validation

A01–A10 + LLM01–LLM10 only. Placeholder strings rejected.

+ Recursive self-review

SELF_REVIEW.md — Crucible reviewing its own pitch. Real findings, not cherry-picked. Regenerable via scripts/self_review.py.

Run it yourself

You'll need an AMD MI300X (or any OpenAI-compatible /v1/chat/completions endpoint), Python 3.11+, and Docker. 

# 1. Clone the repo
git clone https://github.com/leonardtudor11/crucible
cd crucible

# 2. Spin up the panel on the droplet (idempotent)
bash ops/launch_panel.sh <mi300x-ip>

# 3. Tunnel + install
ssh -L 8000:localhost:8000 -N root@<mi300x-ip> &
python -m venv .venv && source .venv/bin/activate
pip install -e .
cp .env.example .env  # set CRUCIBLE_API_KEY=sk-crucible-local

# 4. CLI
python scripts/run_demo.py "Your proposal text here"

# 5. Dashboard
streamlit run src/crucible/ui/app.py

# 6. Eval — multi vs single comparison
python scripts/eval.py
python scripts/eval.py --single-model

# 7. The recursive proof — regenerates SELF_REVIEW.md
python scripts/self_review.py
